# Project conventions

## Pull requests

- **Always open pull requests against the `mpgxc/nestjs-sqs-consumer` repository.**
  This project is a fork of `ssut/nestjs-sqs`; never target the upstream repo as
  the PR base. Every PR — including follow-up work — must be created in
  `mpgxc/nestjs-sqs-consumer` (base branch within this repo).
